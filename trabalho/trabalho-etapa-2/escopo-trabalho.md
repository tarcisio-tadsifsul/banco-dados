# Atividade Avaliativa da Segunda Etapa - Escopo

## Primeira Parte

Descreva uma proposta de modelagem de dados para alguma atividade comercial prática, descrevendo as suas regras de negócios.
Deve possuir uma complexidade mínima para atender um exemplo prático de uma atividade comercial.

> Ao menos 5 tabelas.
> Ao menos 5 funções para facilitar o uso da base de dados.
> Ao menos 10 funções gatilhos para facilitar o uso da base de dados.

## Entregas

> Arquivo com descrição da base de dados e suas regras de negócio.
> Modelo ER
> Arquivo em formato SQL de criação da base de dados com as:
> Tabelas (com dados)
> Funções
> Gatilhos
